# Attribution and academic integrity

## Newly written code and AI assistance
The Python project scaffold, offline indexing, vector retrieval, prompt construction, Gradio integration, automated tests, and setup documentation were authored for this group project with generative AI assistance (OpenAI ChatGPT, October 2026). The group should review, run, and revise code before submission and acknowledge AI assistance according to the course policy. No KDnuggets tutorial source code was copied.
